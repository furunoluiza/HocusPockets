Getting Started

Installation
------------

Clone the repository:

.. code-block:: bash

    git clone https://github.com/furunoluiza/HocusPockets

Enter the project folder:

.. code-block:: bash

    cd HocusPockets

Create a conda environment:

.. code-block:: bash

    conda create -n HocusPockets python=3.10
    conda activate HocusPockets

Install the package:

.. code-block:: bash

    pip install .

if you want to install external software automatically, you can use the following command:

.. code-block:: bash

    hocuspockets-install

----

Open new terminal and activate the conda environment or use the following command to source new changes in the current terminal:
.. code-block:: bash

    source ~/.bashrc

Quickstart
----------

Display usage options:

.. code-block:: bash

    hocuspockets --help

You can use HocusPockets with either a .pdb or .cif file format:
.. code-block:: bash

    hocuspockets -i file.pdb -o output_path
